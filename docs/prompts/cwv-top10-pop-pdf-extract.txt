Introduction (PDF)
------------------
Objective: provide a comprehensive overview of the top pages (or ones the user can select)
key performance elements (CWV, page load, page views) in a period-over-period comparative fashion.

Dashboard Components — Key Metrics Comparative Visualizations (PDF)
------------------------------------------------------------------
Exactly **5 charts** with comparative values for:
  1) Page load time
  2) LCP (Core Web Vital)
  3) INP (Core Web Vital)
  4) CLS (Core Web Vital)
  5) Page views
…for the defined period and filters.

CWV visualizations indicate Google’s performance thresholds per metric:
  Poor / Needs improvement / Good

*Note (PDF): values in these visualizations are an **average of all pages included in the filter**,
which the user can control.

Dashboard Components — Key Metrics Comparative Data Tables (PDF)
---------------------------------------------------------------
Per-page data used to build the visualizations is also provided in tables.

- CLS values are color-coded to Google’s threshold for that metric.
- “Delta metric” color coding = deviation from the comparative period.
- Delta thresholds are visible at the **bottom of the dashboard**:
    • Improvement > 5%
    • Improvement or Degradation of < 5%
    • Degradation > 5%

Filter Options (PDF — authoritative label set for this dashboard)
-----------------------------------------------------------------
- Lookback Period: The period to use and compare
- Comparison Method: Directly vs. previous **or** vs. same period last year
- End date: When the lookback period ends.
    • May be a fixed date
    • For scheduled reports: prefer “matches a user attribute” then
      “start of the month” or “Start of the week” so the sent report covers
      the period leading up to creation time
- Browser: Selection of browsers
- Bot Traffic: Defaults to **exclude bots**
- Device: Desktop or Mobile (browser)
- Operating System: Selection of OS
- Originated from:
    • RUM Browser: Desktop browsers
    • Native App: Native app views (iOS, Android)
    • Webviews: HTML pages rendered inside a mobile application (Hybrid Application Explainer)
- Page Name: Page selector
- Return/New User
- Traffic Segment
- Percentile (applicable only to CWV, **default is 75th percentile**)
- Timezone for the dashboard

Scheduling note (PDF)
---------------------
When scheduling a dashboard report, the report uses the filter settings selected in the dashboard.
If the scheduling dialog’s Filters tab selects other settings, **those override all others**.
(Automation: schedule create is out of scope / cancel-only unless disposable + cleaned up.)
