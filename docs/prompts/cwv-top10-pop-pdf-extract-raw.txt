Introduction
This dashboard's objective is to provide a comprehensive overview of the top pages (or ones the
user can select) key performance elements (CWV, page load, page views) in a period-over-period
comparative fashion.

Dashboard Components
Key Metrics Comparative Visualizations
In these 5 charts, the user can find the comparative values for page load time, the Core Web Vitals
(LCP, INP, CLS), and page views for the defined period and filters (see Filter Options below). The CWV
visualizations indicate Google's definitions for performance thresholds per metric (Poor, Needs
improvement, Good).
*Note that the values represented in these visualizations are an average of all pages included in the filter, which the
user can control.

Key Metrics Comparative Data Tables
In addition, the data used to build the above visualizations is provided per page.
The CLS values are color-coded to represent Google's threshold for that metric.
The "Delta metric" color coding represents the deviation from the comparative period. These
thresholds are visible at the bottom of the dashboard:
Improvement > 5%
Improvement or Degradation of < 5%
Degradation > 5%
