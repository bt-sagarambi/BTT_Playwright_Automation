Overview
The Conversions Over Time Widget shows you the real time conversion rate, average order value
and performance for any and all traffic segments visiting your site. This widget gives you insight into
how average order value and conversion rate are affected due to performance.
Click the legend items to hide or show the lines in the graph.
Find Widget
Once you enter the Add a Widget menu, you will see a variety of filter options on top. One way to find
the Conversions Over Time Widget is to use the filter options listed below.
Filter Title
Filter Option
Widget Type
Trends
Data Type
Real User
Insight Type
Business
Another way to find the Conversions Over Time Widget is to use the search bar at the top right of the
menu.
Widget Configuration
To configure this widget, fill out all required sections and apply any filtering you need.
Note: You cannot use the page name filter option in the Conversions Over Time widget.
