--- Introduction / purpose ---
Dashboard categorizes URLs into Google CWV performance buckets:
  • Good
  • Needs Improvement
  • Poor
and visualizes daily URL-count distribution plus per-URL CWV performance detail.

--- Dashboard Components (Help) ---
1) URL Performance Category Distribution
   - Line chart displays up to ~3,000 URLs daily (Help), organized into a daily distribution of:
       Good / Needs Improvement / Poor
   - Table below the graph represents the same data in tabular form.

2) Daily Distribution of URLs by Category
   - Table view of the line-chart data
   - Columns organize daily counts into Good / Needs Improvement / Poor threshold categories
   - Displays up to ~3,000 URLs (Help wording for the distribution)

3) Performance Category by URL
   - Breaks down each unique URL that appeared in the period on the line chart
   - Shows corresponding performance category, sorted by hits
   - Number of URLs can exceed 3,000 because URLs can change day to day
   - Table limited to ~5,000 rows (Help)

--- CWV Threshold Values (Google bands — Help) ---
Google defines three threshold categories: Good, Needs Improvement, Poor.
(Exact numeric LCP/INP/CLS thresholds are Google-defined and may change — soft-assert band LABELS,
 not hard-code threshold numbers from any single probe.)

--- How URLs are Specified to a Category (Help — critical business rule) ---
• Poor: Any ONE of the CWV for the URL is “Poor” by Google’s threshold definition
• Needs improvement: None of the CWV for the URL are “Poor”, but at least ONE is “Needs improvement”
• Good: ALL of the CWV metrics are in the “Good” Google threshold
