Overview (pp.1–2)
- Algorithm based on Sessions to identify/quantify key influences driving weekly revenue changes.
- Experience Influences = Performance + Stability.
- Marketing Influences = Sessions, Average Order Value, and Intent.
- Combined → overall Revenue Influence.
- Best practice: pick a meaningful comparison date (e.g. rollout of a performance improvement) and compare week before vs after.
- Default cadence: report runs once every week on Monday (PDF typo: “once everyone week”).
- PLEASE NOTE: All devices includes tablet, but tablet is NOT its own category. Selecting both
  “Desktop” and “Mobile” will NOT show All Devices data (excludes Tablet).

Five influences (pp.2–4)
Experience
| Influence   | Definition (PDF) |
| Performance | Willingness to stay engaged / complete journey; impacts conversion & revenue. Faster onload often helps but not always (Friction Five blog soft). |
| Stability   | Page reliability / content stability revenue tendency (missing content, slow images, inconsistent key features). |
Experience example: slight onload improvement → more sessions in higher conversion-curve area; flattened curve also desirable (consistency). Optimize for non-ideal experiences (prioritize key elements, earlier interaction, progressive content, communicate delays).

Marketing
| Influence           | Definition (PDF) |
| Traffic             | WoW session volume change (campaigns/seasonality). PDF intro says “Sessions”; influence table label is Traffic. |
| Average Order Value | Impact of AOV change (pricing/packaging/promotions). |
| Intent              | Tendency to complete journey/convert with other influences held constant. |
Marketing example: good campaign + wrong product → Sessions up, Intent negative (audience/offering mismatch).

Section 1: Revenue Attribution (pp.5–6)
- Top section: calculated revenue attributed from each influence (succinct view of sections 2 & 3).
- Device Selection controls which device visuals are visible.

KPI Change (pp.5–6) — uses ALL filters EXCEPT SELECTED PAGE NAME
- Actual measured revenue / KPI differences week over week:
  - Sessions — WoW session delta (+ increase / − decrease)
  - Average Order Value — WoW AOV delta
  - Conversion Rate — WoW delta in **basis points** (1 bps = 1/100th of a percentage)
  - Revenue Per Session — WoW average revenue per session delta

Section 2: Revenue Attribution by Platform (p.7)
- Influence data by platform/device.
- Each bar = individual influence; whisker = revenue attributed to Influence Group.
- Legend below chart; hover bar/whisker for exact value.
- Bar right/green = positive vs prior period; left/red = negative.

Section 3: Revenue Attribution by Page (pp.7–8)
- Page-by-page influence data in bar chart + table (table underneath page-level charts).
- Same bar/whisker/legend/hover/direction semantics as Platform.
- Explicit: **Scaling is not applied to data at the page level.**
- PDF includes Chart example + Table example images (no machine-readable headers beyond prose).

Navigating (pp.8–11)
Left Navigation
- Business Insights → Improve Conversion → Revenue Attribution
- Soft: menu search bar (PDF typo “at the to of the menu”)

Filtering
- Filter icon top-right.
- Updating filters + press **“Save & Run Report”** triggers a new report run.
- Optional custom report name, else default name = site title + date of performance change being measured.
- All filters impact entire report **except page name** — page name does **not** impact the KPI Changes column.

Running a New Report
- Default auto-run at start of each fiscal week (PDF typo “By default, he Revenue Attribution…”).
- First processing of a new report: **5 to 20 minutes**; subsequent views via report selection dropdown load instantly.

Report Selection
- Dropdown top-left lists previously run reports.
- Selecting a report loads that report + associated filters.

Device Selection (PDF set)
- Desktop / Mobile / All Devices buttons (top left).
- Outlined in blue = visible; grayed out = hidden; remaining visuals fill width.
- Repeats PLEASE NOTE tablet caveat.

Scaling (pp.11–12)
- KPI change / measured differences = actual revenue differences.
- Influences scaled to match measured difference when prediction direction matches actual.
- If predict positive but actual negative (or vice versa), scaling not applied; UI shows an **artifact** that scaling was not applied (often when numbers near 0 / variance).
- PLEASE NOTE again: Scaling does not get applied to page level data.
