Overview
The Competitive Index is a module available in the Blue Triangle Portal designed for customers to
gain deeper insight into the Industry Benchmarks, enabling eCommerce site owners to see how their
site stacks up against the competition.

The Industry Benchmarks are a list of more than 1500 sites organized by industry featuring a few
performance metrics comparing data from the week prior to the current date, available to be viewed
on our site.  Each industry is then sorted into a more specific vertical; for example, the Retail
industry is subcategorized and includes a vertical called Apparel and Accessories. 
Accessing the Competitive Index
The Competitive Index is found in the Blue Triangle Portal via the left side navigation menu.
There are two ways to view the Competitive Index: Table view and Trends view.

Trends view
The Trends view allows you to compile custom graphs to better analyze the data. You can trend
multiple sites at a time or view the average of the selected metric for the selected industry.
About the Competitive Index
The Competitive Index enables you to have complete access to the Industry Benchmarks data as
well as allowing you to view the industry averages for over 40 different performance metrics, some
coming from Google Lighthouse API and the rest being collected by Blue Triangle's synthetic
monitors. This allows you to compare your sites data with your competitors. You can view the data
over any time period, the only limitation being when we started collecting the data. There is a video
explaining the functionality and includes a live walkthrough of the Competitive index available here.
