Overview
The Blue Triangle Announcements widget displays recently posted announcements in the
Dashboard; including but not limited to newest release notes, new feature releases, or any relevant
outages. 
Find Widget
Once you enter the Add a Widget menu, you will see a variety of filter options on top. One way to find
the Blue Triangle Announcements Widget is to use the filter options listed below.
Filter Title
Filter Option
Widget Type
Alerts/Notifications
Data Type
N/A
Insight Type
N/A
Another way to find the Blue Triangle Announcements Widget is to use the search bar at the top right
of the menu.
Widget Configuration
To configure this widget, you are only required to give the widget a title.
