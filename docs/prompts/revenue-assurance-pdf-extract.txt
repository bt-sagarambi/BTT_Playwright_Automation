Product purpose (Help):
- Single-pane-of-glass portal that translates web/mobile performance data into dollars of recoverable revenue.
- Money-ranked backlog with user story + acceptance criteria already written for engineering hand-off.
- Closes the loop between observability (Blue Triangle RUM, Chrome CrUX, Android Vitals) and execution
  (tickets, status tracking, realized-revenue attribution).

Audiences (Help):
- Executives / revenue owners — total annualized opportunity, recognized-vs-remaining progress, forecast.
- Product managers — ranked, filterable backlog by platform and sub-area.
- Engineers — fully-formed recommendations (analysis, user story, acceptance criteria, expected result, source metrics).

Key concepts (Help):
- Annualized opportunity — estimated yearly revenue lift if opportunity fully realized.
- Recognized revenue — opportunity already captured by implemented recommendations (green progress bar).
- Platform — Browser / iOS Mobile App / Android Mobile App + global All.
- Recommendation status — New → In Progress → Implemented; plus Internal Review staging for drafts.
  (Live GDC also exposes Declined and Internal Declined — prefer live status inventory.)
- Estimated effort — Large / Medium / Small (L/M/S), editable inline.
- Source metrics — Blue Triangle RUM, Chrome CrUX, Android Vitals, CWV (INP/LCP/CLS), Macrobenchmark, Baseline Profiles.

Landing dashboard (Help):
- Hero card: total annualized opportunity; recognized-vs-remaining progress; donuts for Recommendations by State
  and Opportunity by Platform; platform toggle re-scopes dashboard.
- Revenue Opportunities: money-ranked cards by platform; Compact/Relaxed density; Coming Soon for not-ready items.
- Show Me deep-links into All Recommendations table (sortable/filterable/paginated): Recommendation, Revenue
  Opportunity, Effort, Revenue Realized, Status, Platform, Created date.
- Rich cards / expand: parent opportunity, annualized lift, realized revenue, Status + Effort dropdowns,
  Expand / Share / Feedback; Detailed Analysis with source-metric chips; User Story; Acceptance Criteria;
  Expected Result.
