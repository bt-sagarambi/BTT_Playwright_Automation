Introduction (Help / PDF family)
----------------------------------
This set of dashboards offers a comprehensive overview of the key metrics for users,
in a comparative manner.

Predefined time periods for these dashboards:
  • Daily, Weekly
  • Monthly, Quarterly

There are 8 different dashboards, one for each predefined time period listed above,
addressing unique aspects of performance:

  • Revenue Dashboard
      - Conversion Rate %
      - Sales $
      - Average Order Value $
      - Revenue per paying User $
      - Revenue per Session $
  • UX Metrics  ← **Monthly/Quarterly - UX Metrics (THIS suite)**
      - Onload (Seconds)
      - LCP (Seconds)
      - CLS (Score)
      - INP (Seconds)
  • Bounces
      - Bounce Rate %
  • Traffic
      - Unique Visitors
      - Returning Visitors
      - Sessions
      - Session Duration (seconds)

Dashboard Components — Key Metrics Visualizations (Help / PDF)
-------------------------------------------------------------
In each of these dashboards, for each metric, the timeframe, KPI and the comparative
trendline are shown. Example: INP value charted for daily vs weekly comparative views.

Filter Options (Help / PDF — authoritative inventory; map live labels below)
-----------------------------------------------------------------------------
- End Date: According to the period used in the dashboard (daily/weekly/monthly/quarterly),
    this would be the first date to be excluded from the dashboard.
    • May be a fixed date
    • For scheduled dashboards: prefer "matches a user attribute" then
      "start of the month" or "Start of the week" so the sent report covers
      the period leading up to creation time
- Comparison Method: Directly vs. previous **or** vs. same period last year
    (Live UI label: **Comparison Period** with options including
    Default (from chart), Directly Previous Period, Same Time Last Year)
- Browser: Selection of browsers
- Bot Traffic: Defaults to exclude bots
- Device: Desktop or Mobile (browser)
- Operating System: Selection of OS
- Originated from:
    • RUM Browser: Desktop browsers
    • Native App: Native app views (iOS, Android)
    • Webviews: HTML pages rendered inside a mobile application
- Page Name: Page selector
- Return/New User  (Live: **Return/New Visitor**)
- Traffic Segment
- Percentile (applicable only to CWV, **default is 75th percentile**)

Scheduling note (Help / PDF)
----------------------------
When scheduling a dashboard report, the report uses the filter settings selected in
the dashboard. If the scheduling dialog Filters tab selects other settings, those
override all others. (Automation: schedule create cancel-only / out of scope unless disposable.)
