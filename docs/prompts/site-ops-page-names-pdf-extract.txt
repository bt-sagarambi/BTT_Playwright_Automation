Introduction
This dashboard offers an overview of the key CWV values on a monthly basis for each page in the
defined set. In this report, each CWV metric is trended over time for each page separately.

Dashboard Components
Monthly CWV Per Page Metrics 
In each metric chart, each page is trended. The timespan bucketing depends on the selection of the
total report timespan.
In the table, the metric is provided per page on a monthly basis.  
The CWV coloring indicates Google's definitions for performance thresholds per metric (Poor, Needs
Improvement, Good).

Filter Options
Time Period: The period to use for the dashboard. This value can be fixed, however for
scheduled dashboard, it is recommended to use "matches a user attribute" and then select
"start of the month" or "Start of the week" so that when the dashboard is sent, it includes the
period leading to the time the dashboard is created.
Bot Traffic: Defaults to exclude bots
Device: Desktop or Mobile (browser)
Origin
RUM Browser: Desktop browsers
Native App: Native app views (iOS, Android)
Webviews: HTML pages that are rendered inside a mobile application (Hybrid Application
Explainer) 
Page Name: Page selector
Return/New User
Traffic Segment
Page Group
Timezone
Percentile (applicable only to CWV, default is 75th percentile)
