# Synthetic Performance Detail — documentation extracts (Aug 2026)

## A) Official preconfigured DASHBOARD help (primary for this suite)
Article: https://help.bluetriangle.com/hc/en-us/articles/360033776353-The-Synthetic-Performance-Detail-Dashboard
Title: The Synthetic Performance Detail Dashboard

Overview (public summary):
- The Synthetic Performance Detail page enables analysis of synthetic data from high-level glance down to individual page measurements.
- Top of page: customize time period to analyze.
- Access: Portal menu → Dashboards; preconfigured dropdown on left; alternate gear → Dashboard Manager → eye.
- Auto-refresh: as low as every 2 minutes up to once every hour.
Widgets:
- Bar Graph & Details cards: high-level overview; selecting a metric updates bar graph by page AND Daily Averages bottom widget.
- Performance Graph: Page Timings Over Time for All Matched Pages; gear controls included metrics; legend toggles series.
- Daily Averages: table of daily averages for metric selected in Details, by page name and date.
Filters:
- Filter icon top right → criteria → Apply reloads; time period selector top left.
